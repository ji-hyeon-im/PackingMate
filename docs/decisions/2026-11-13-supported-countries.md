# MVP 지원 국가와 도시 기본값

- 결정일: 2026-11-13
- 상태: 적용

## 지원 국가

MVP는 일본(`JP`), 베트남(`VN`), 미국(`US`), 태국(`TH`), 대만(`TW`)만 지원한다. UI는 한국어 국가명을 드롭다운에 표시하고 API에는 ISO alpha-2 코드를 보낸다. `GET /api/v1/countries`와 체크리스트 생성 서버 검증은 동일한 `CountryCatalog` 자료를 사용한다.

목록 선택 근거는 최종 설계 문서가 인용한 [한국관광공사 2026년 9월 목적지 통계](https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1127&bcIdx=311491)다. 코드 변경 시점에는 원자료와 첨부 통계를 재검증하지 않았다.

## 도시 기본값

도시를 비우면 일본-도쿄, 베트남-하노이, 미국-워싱턴 D.C., 태국-방콕, 대만-타이베이를 사용한다. 대표 도시를 수도로 해석한 자체 가정이며 날씨/지오코딩 공식 자료에 따른 확정 기준은 아니다.

도시 입력은 체크리스트 규칙에 쓰지 않는다. 현재는 응답의 여행 요약에 표시하고, 향후 날씨 조회에 사용할 예정이다. 도시의 오타나 국가 불일치는 지오코딩이 연결된 뒤 해당 국가에 한정해 판정하고 재입력을 요청해야 한다.
