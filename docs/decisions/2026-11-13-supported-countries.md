# MVP 지원 국가와 도시 기본값

- 결정일: 2026-11-13
- 상태: 적용 (선정 통계 원자료 재검증 필요)

## 지원 국가

MVP는 일본(`JP`), 베트남(`VN`), 미국(`US`), 태국(`TH`), 대만(`TW`)만 지원한다. UI는 한국어 국가명을 드롭다운에 표시하고 API에는 ISO alpha-2 코드를 보낸다. `GET /api/v1/countries`와 체크리스트 생성 서버 검증은 동일한 `CountryCatalog` 자료를 사용한다.

초기 목록은 최종 설계 문서가 인용한 [한국관광공사 2026년 1~9월 목적지 통계](https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1127&bcIdx=311491)를 선정 근거로 삼았다. 구현 시 원자료 파일과 통계 정의를 독립적으로 재검증하지 않았으므로, 이 수치는 최신 수요 순위의 확인된 근거가 아니라 초기 제품 선택의 참고값이다. 목록을 확장·재선정할 때 원자료와 집계 기준을 확인한다.

## 도시 기본값

도시를 비우면 일본-도쿄, 베트남-하노이, 미국-워싱턴 D.C., 태국-방콕, 대만-타이베이를 사용한다. 대표 도시를 수도로 해석한 자체 가정이며 날씨/지오코딩 공식 자료에 따른 확정 기준은 아니다.

도시 입력은 준비물 규칙 태그에는 쓰지 않지만, 날씨 조회를 위해 Open-Meteo 지오코딩에 국가 코드와 함께 전달한다. 국가 내 지오코딩 결과가 없으면 API는 `400 INVALID_TRIP`을 반환해 도시와 국가를 확인하도록 요청한다. 지오코딩 서비스 자체가 실패하면 날씨를 `UNAVAILABLE`로 처리하고 체크리스트 생성을 계속한다. 근거와 전체 fallback 동작은 [`sources-and-rules.md`](../sources-and-rules.md) 및 [`checklist-api.md`](../api/checklist-api.md)에 둔다.
